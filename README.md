# Tic-Tac-Toe with Simple AI 🎮

## CodeOrbit Tech Internship – Task 2

### 👩‍💻 Project Overview
This project is a Python-based Tic-Tac-Toe game where a human player competes against a computer opponent using simple AI rules.

The computer can identify its winning move, block the player's winning move, and choose strategic positions on the board.

### 🎯 Project Objectives
- Develop a Tic-Tac-Toe game using Python.
- Implement a simple rule-based AI for the computer.
- Display the game board after every move.
- Detect player wins, computer wins, and draws.
- Practice Python functions, loops, conditions, and lists.

### ✨ Features
- Human vs Computer gameplay.
- Player uses X and Computer uses O.
- Computer checks for winning opportunities.
- Computer blocks the player's winning move.
- Prefers the center and corner positions.
- Detects win, loss, and draw conditions.
- Handles invalid and occupied positions.

### 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Visual Studio Code
- Random Module

### 🧠 AI Logic
The computer follows simple rules:
1. Checks whether it can win.
2. Blocks the player's winning move.
3. Chooses the center if available.
4. Prefers an empty corner.
5. Selects any remaining empty position.

### ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python tictactoe.py
```

5. Enter a position between 1 and 9 to play.

### 🎮 Board Positions

```text
 1 | 2 | 3
---|---|---
 4 | 5 | 6
---|---|---
 7 | 8 | 9
```
